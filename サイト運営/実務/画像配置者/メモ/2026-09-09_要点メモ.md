# 2026-09-09 画像配置 要点メモ(家計調査2025_支出の内訳)

- 画像ライブラリの実体パスは `画像フォルダ\各種サイト\お金サイト\ライブラリ` 直下(記事用フォルダは介さない)。「記事用」「使用済み」はライブラリと同階層のフォルダ名として存在せず、`使用済み`はお金サイト直下にある。プロジェクトごとにフォルダ構成が微妙に違う可能性があるため、作業前に必ず`ls`で実パスを確認する
- 元画像は1448×1086(ほぼ4:3)。サムネイル規格1536×864(16:9)に合わせるため、Pillowで中央クロップしてからリサイズする必要があった。本文画像は16:9指定がないためクロップ不要でそのまま変換
- 対象記事が`確定稿\`配下のみのケースでは`content\articles\`側は存在しないため、確定稿1ファイルのみの編集で完了(公開済みとの二重編集は不要)
- 目視確認の結果、image-selectorのalt文案(付箋の分類/電卓・ノート・机)と画像の実際の内容は一致しており、人物の構図にも記事テーマとの矛盾はなかった
- CATALOG.mdは当該2枚が未記載(新規生成分)だったため、既存の記載形式に合わせて新規行を追加した。ついでに近くにあった未確認の別画像(20_40_05.png)を推測で記載しそうになったが、目視していないものを記載するのは誤情報のリスクがあるため見送った
- git addは自分が変更した3ファイル(サムネイルwebp・本文画像webp・確定稿md)のみを明示指定し、他の未関連の未追跡ファイル(publisher.md変更や他エージェントの成果物)を巻き込まないよう注意した
