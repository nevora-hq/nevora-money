「貯蓄の平均は1,940万円」と見かけたあと、自分の残高を確かめて、画面をそっと閉じたくなったことはありませんか😳 1,940万円を出した金融経済教育推進機構(J-FLEC)の調査には、中央値720万円という数字もあって%%出典:J-FLEC 調査結果の概要%%、どちらを自分と並べればいいのか迷いますよね。平均と中央値の違い、貯蓄の数え方、調査ごとの数字の違いを、詳しく説明していきます。

## 二人以上世帯の貯蓄、平均と中央値のどちらを自分と並べればいい？

ニュースやSNSで貯蓄の数字を見かけたとき、その数字が1つだけとは限りません。同じ記事に平均と中央値が並んでいたり、別の記事に違う金額が出ていたりして、どれが自分の世帯と並べる数字なのか分からなくなりませんか💦 見かけやすい数字を、調査ごとに並べると、1つの調査だけで2つ、調査が変わるとさらに増えます。

| 見かける数字 | どの調査の、何の数字か |
|---|---|
| 1,940万円 | J-FLEC「家計の金融行動に関する世論調査」2025年の、二人以上世帯の金融資産保有額の平均%%出典:J-FLEC ポイント%% |
| 720万円 | 同じ調査の、二人以上世帯の金融資産保有額の中央値%%出典:J-FLEC 調査結果の概要%% |
| 919万円 | 同じ調査の、単身世帯の金融資産保有額の平均%%出典:J-FLEC ポイント%% |
| 2,059万円 | 総務省統計局「家計調査」貯蓄・負債編の2025年平均の、二人以上の世帯の貯蓄現在高の平均%%出典:総務省統計局 家計調査 貯蓄・負債編 2025年平均%% |
| 1,264万円 | 同じ家計調査の、貯蓄がある世帯の中央値%%出典:総務省統計局 家計調査 貯蓄・負債編 2025年平均%% |

どれも2025年の調査結果で、2026年11月時点で公表されている数字です。ただ、調査も数字の名前も違うので、同じ「貯蓄」という言葉でも、どの数字を相手にするかで自分の位置は違って見えます。仮に手元の合計が平均と中央値の間の金額だとすると、平均1,940万円と並べれば下に、中央値720万円と並べれば上に見えるのです。1,940万円と720万円は、なぜここまで離れているのでしょうか？

## 平均1,940万円と中央値720万円は、何が違う数字？

平均は、全員の金額を足して世帯数で割った数字で、少数のたくさん持っている世帯に引き上げられて高く出ます%%出典:J-FLEC 調査結果の概要%%。中央値は、金額の少ない順に並べたときの、真ん中の世帯の金額です%%出典:J-FLEC 調査結果の概要%%。説明用に作られた9世帯の例で、違いを見てみましょう。実際の調査結果ではありません。

### 9世帯の例では、平均より下の世帯はいくつある？

この例では、金額順に並べた真ん中の世帯Eが720万円で、これが中央値です。9世帯の平均は1,940万円ですが、これを超えているのは世帯G・H・Iの3世帯だけで、世帯Eを含む残りの6世帯は平均より下です%%出典:J-FLEC 調査結果の概要%%。平均だけを見ると、多くの世帯が実感とかけ離れた印象をもつことになります%%出典:J-FLEC 調査結果の概要%%。

世帯Eのように中央値にあたる世帯から見ると、ちょうど半分の世帯が自分より多く、ちょうど半分の世帯が自分より少なく持っています%%出典:J-FLEC 調査結果の概要%%。そのため、中央値は世帯全体の実感により近い数字になると考えられます%%出典:J-FLEC 調査結果の概要%%。平均も中央値も、同じ分布を別の側から見た数字です。

![大きさの異なる白いブタの貯金箱が、小さい順に木の机に並び、手前に白紙のノートとペンがある写真](/images/articles/2026-10-07_貯蓄の平均と中央値二人以上世帯_body1.webp)

### 720万円の真ん中に、0円の世帯は入っている？

では、実際の720万円は、どの世帯の真ん中でしょうか。調査の金額別の世帯数の表には、金融資産が0円の世帯が784世帯あります%%出典:J-FLEC 調査結果の概要%%。中央値の720万円は、その0円の世帯も並べた順番の真ん中で、==0円の世帯も入れた真ん中==です。

| 調査の比率 | 何を数えているか |
|---|---|
| 金融資産が0円の世帯 | 運用のため、または将来に備えて蓄えている金融商品がない世帯。日常の出し入れ用の預貯金は数えない%%出典:J-FLEC 調査結果の概要%% |
| 金融商品を「いずれも保有していない」世帯は5.4%(2025年) | 上に加えて、日常の出し入れ用の預貯金も含めて、何も持たない世帯%%出典:J-FLEC 調査結果の概要%% |

つまり、金融資産が0円の世帯は、日常用の預貯金まで何も持たない世帯と同じとは限りません。

金額別の世帯数の表は、両端まで世帯が並んでいます。

| 金融資産保有額 | 世帯数(2025年) |
|---|---|
| 0円 | 784世帯%%出典:J-FLEC 調査結果の概要%% |
| 1〜100万円未満 | 379世帯%%出典:J-FLEC 調査結果の概要%% |
| 1億円以上 | 155世帯%%出典:J-FLEC 調査結果の概要%% |

1億円以上の世帯が混ざるほど、平均は引き上げられます。720万円は、その両端の影響を受けにくい真ん中の金額です。

720万円は自分が超えるべき目標ではないので、足りる・足りないを決める線にするのは避けてください。自分の世帯が分布のどのあたりかを知る材料として見るのが、この数字の使いどころです。

### 通帳の残高を全部足した金額と、調査の「金融資産」は同じ？

自分の残高と並べたくなったとき、差が出やすいのは数える範囲です。調査の「金融資産」は、運用のため、または将来に備えて蓄えている部分だけで、通帳やアプリの残高を全部足した金額とは数え方が違います%%出典:J-FLEC 調査結果の概要%%。

| 手元にあるもの | 調査の「金融資産」 |
|---|---|
| 日常的な出し入れ・引落しに備えている預貯金 | 入らない%%出典:J-FLEC 調査結果の概要%% |
| 運用のため、または将来に備えて蓄えている預貯金 | 入る%%出典:J-FLEC 調査結果の概要%% |
| 積立型の保険、個人年金保険、債券、株式、投資信託、財形貯蓄 | 入る%%出典:J-FLEC ポイント%% |
| 現金、土地・住宅・貴金属などの実物資産 | 入らない%%出典:J-FLEC 調査結果の概要%% |

総務省の家計調査の貯蓄現在高は、調査が別です。内訳には通貨性預貯金710万円も入っていて%%出典:総務省統計局 家計調査 貯蓄・負債編 2025年平均%%、J-FLECの金融資産と同じ線引きとは限りません💦 数字を見かけた記事の注記で、^^調査名と対象の世帯^^を見てみてください。

## 別の年や別の調査の数字と並べると、貯蓄の見え方はどう変わる？

平均と中央値の違いが分かっても、見かけた数字が別の年や別の調査のものだと、並べ方でまた迷います。

### 家計調査の平均を下回る世帯は、どれくらい？

総務省統計局の家計調査では、2025年平均の二人以上の世帯の貯蓄現在高の平均が2,059万円で、これを下回る世帯は66.1%と約3分の2を占めています%%出典:総務省統計局 家計調査 貯蓄・負債編 2025年平均%%。貯蓄現在高の少ない階級に偏った分布になっているのです%%出典:総務省統計局 家計調査 貯蓄・負債編 2025年平均%%。平均を自分の貯蓄の合格ラインのように読むと、約3分の2の世帯が下に入ってしまいます😓

家計調査の貯蓄現在高は、中身の分け方もJ-FLECの金融資産とは別です。2025年平均の二人以上の世帯では、貯蓄現在高2,059万円の内訳は次のとおりです。

| 貯蓄の種類 | 1世帯あたり(構成比) |
|---|---|
| 通貨性預貯金 | 710万円(34.5%)%%出典:総務省統計局 家計調査 貯蓄・負債編 2025年平均%% |
| 定期性預貯金 | 511万円(24.8%)%%出典:総務省統計局 家計調査 貯蓄・負債編 2025年平均%% |
| 有価証券 | 440万円(21.4%)%%出典:総務省統計局 家計調査 貯蓄・負債編 2025年平均%% |
| 生命保険など | 369万円(17.9%)%%出典:総務省統計局 家計調査 貯蓄・負債編 2025年平均%% |
| 金融機関外 | 29万円(1.4%)%%出典:総務省統計局 家計調査 貯蓄・負債編 2025年平均%% |

通貨性預貯金が最も多く、貯蓄現在高の3分の1あまりを占めています。この家計調査の数字と、日常用の預貯金を除いたJ-FLECの数字を同じ物差しで並べると、数え方の違いが差に混ざってしまいます。

### 2024年の350万円とは、並べていい？

J-FLECの調査では、年によって数字が動きます。2025年は平均1,940万円・中央値720万円で、2024年は平均1,374万円・中央値350万円でした%%出典:J-FLEC 調査結果の概要%%。年が違う数字は、その年の調査の結果として別々に読みましょう。2024年の350万円を見かけたあとに、2025年の720万円を見かけて、増えたのかと迷う場合は、次の表と注で、調査の方法が変わった年をまたいでいないかを見てみてください。

| 調査の年 | 平均 | 中央値 |
|---|---|---|
| 2021年 | 1,563万円%%出典:J-FLEC 調査結果の概要%% | 450万円%%出典:J-FLEC 調査結果の概要%% |
| 2022年 | 1,291万円%%出典:J-FLEC 調査結果の概要%% | 400万円%%出典:J-FLEC 調査結果の概要%% |
| 2023年 | 1,307万円%%出典:J-FLEC 調査結果の概要%% | 330万円%%出典:J-FLEC 調査結果の概要%% |
| 2024年 | 1,374万円%%出典:J-FLEC 調査結果の概要%% | 350万円%%出典:J-FLEC 調査結果の概要%% |
| 2025年 | 1,940万円%%出典:J-FLEC 調査結果の概要%% | 720万円%%出典:J-FLEC 調査結果の概要%% |

概要の共通の注には、調査の方法の変更から2019年〜2021年のデータは不連続であることに注意、と書かれています%%出典:J-FLEC 調査結果の概要%%。2021年の調査では、調査手法・対象の大幅な見直しがありました%%出典:J-FLEC ポイント%%。データが不連続になる時点は、2020年調査と2021年調査の間までで、2021年以降の調査どうしの間にはありません%%出典:J-FLEC 統計表の利用上の注意%%。増えた・減ったと比べたいときは、方法が変わった年をまたいでいないかを、先にこの注で確かめてください。またいだ数字どうしの差は、同じ物差しの差とは言えません。

### 家計調査の1,264万円は、720万円と何が違う？

J-FLECの720万円と家計調査の1,264万円は、中央値という名前は同じでも、取り方が違います。

| | J-FLEC | 家計調査 |
|---|---|---|
| 調査 | 金融経済教育推進機構「家計の金融行動に関する世論調査」%%出典:J-FLEC 調査結果ページ%% | 総務省統計局「家計調査」の貯蓄・負債編%%出典:総務省統計局 家計調査 貯蓄・負債編 2025年平均%% |
| 数字の名前 | 金融資産保有額%%出典:J-FLEC 調査結果の概要%% | 貯蓄現在高%%出典:総務省統計局 家計調査 貯蓄・負債編 2025年平均%% |
| 中央値の取り方 | 0円の世帯も入れて並べた真ん中%%出典:J-FLEC 調査結果の概要%% | 貯蓄が0の世帯を除いて並べた真ん中。0の世帯も入れた参考値は1,167万円%%出典:総務省統計局 家計調査 貯蓄・負債編 2025年平均%% |
| 調べた時期 | 2025年6月20日〜7月2日%%出典:J-FLEC 調査結果ページ%% | 2025年の1〜12月に調査された世帯の年平均%%出典:総務省統計局 家計調査 時系列比較ページ%% |

名前も取り方も時期も別なので、720万円と1,264万円の大小を比べて、どちらが正しいかを決めることはできません。見かけた数字がどちらの調査のものかを、先に確かめてください。

## 自分の貯蓄は、どの数字の、どの区分と並べる？

自分の貯蓄を並べたくなったとき、金額だけを調査の数字と見比べても、差の意味は読めません。おすすめは、調査と同じ数え方で自分の金額を出し直し、世帯の形が近い区分の中央値と並べる順番です。調査の数字は自分の貯蓄を採点するものではなく、数え方と区分をそろえたときに初めて読める材料です。

### 自分の分は、調査と同じ数え方で足す

調査票には、金融商品ごとの数え方が書かれています%%出典:J-FLEC 調査結果(単純集計データ)%%。通帳の残高だけでなく、保険や株も、この数え方で足してみてください。

| 金融商品 | 調査票での数え方 |
|---|---|
| 生命保険・損害保険 | これまでに払い込んだ保険料の総額。すでに給付を受けた分、掛け捨ての保険、年金型商品は除く%%出典:J-FLEC 調査結果(単純集計データ)%% |
| 個人年金保険 | これまでに積み立てた掛け金の総額。公的年金の掛け金は除く%%出典:J-FLEC 調査結果(単純集計データ)%% |
| 株式・投資信託・債券 | 時価(現在の相場)。不明なら額面でもよい%%出典:J-FLEC 調査結果(単純集計データ)%% |
| 外貨建ての商品 | 円に換算した額で含める%%出典:J-FLEC 調査結果(単純集計データ)%% |
| NISA・iDeCoの中身 | 含める。iDeCoの定期預金・投資信託・保険商品は、それぞれの種類に入れる%%出典:J-FLEC 調査結果(単純集計データ)%% |
| 事業のために持っている金融商品 | 除く%%出典:J-FLEC 調査結果(単純集計データ)%% |

足し始める前に、口座ごとに、日常の出し入れや引き落としに備えている分と、運用や将来に備えている分を分けておくと迷いません。紙かアプリのメモに、口座の名前と、どちらの分かを書き出してみてください。分けた残りに保険と株や投資信託を表のとおりに足せば、調査の「金融資産」に近い金額になります。

![方眼ノートに、ペンで小さな丸を書こうとしている手元の写真](/images/articles/2026-10-07_貯蓄の平均と中央値二人以上世帯_body2.webp)

数え方をそろえないまま並べると、差が貯蓄の差ではなく、数え方の差で出てしまいます。足した金額は、年に1回など決めた時期に、^^自分の金額を書き残して^^おくと、次の年の自分と同じ物差しで並べられます。

### 世帯の形・年齢・借入れで、見る数字が変わる

並べる相手は、二人以上世帯全体の数字だけとは限りません。家計調査には二人以上の世帯を区分した結果もあり、勤労者世帯は二人以上の世帯の56.2%を占めています%%出典:総務省統計局 家計調査 貯蓄・負債編 2025年平均%%。

| 区分 | 貯蓄現在高の平均 | 貯蓄がある世帯の中央値 |
|---|---|---|
| 二人以上の世帯全体 | 2,059万円%%出典:総務省統計局 家計調査 貯蓄・負債編 2025年平均%% | 1,264万円%%出典:総務省統計局 家計調査 貯蓄・負債編 2025年平均%% |
| うち勤労者世帯 | 1,717万円%%出典:総務省統計局 家計調査 貯蓄・負債編 2025年平均%% | 1,015万円%%出典:総務省統計局 家計調査 貯蓄・負債編 2025年平均%% |

勤労者世帯は、平均も貯蓄がある世帯の中央値も、二人以上の世帯全体より少なくなっています%%出典:総務省統計局 家計調査 貯蓄・負債編 2025年平均%%。世帯主の年齢の階級別に貯蓄現在高の平均を見ると、40歳未満が994万円と最も少なく、60歳以上の各年齢階級では2,000万円を超えています%%出典:総務省統計局 家計調査 貯蓄・負債編 2025年平均%%。

J-FLECの調査結果ページには、年齢別・職業別・収入別・地域別などの集計をまとめた「各種分類別データ」があります%%出典:J-FLEC 調査結果ページ%%。区分の分け方は、統計表の利用上の注意に書かれています。

| 区分 | 分け方 |
|---|---|
| 世帯主の年令別 | 6分類%%出典:J-FLEC 統計表の利用上の注意%% |
| 年間手取り収入別 | 世帯全員の1年間の税引後の手取り収入で7階層%%出典:J-FLEC 統計表の利用上の注意%% |
| 持家別 | 持家と非持家の2分類%%出典:J-FLEC 統計表の利用上の注意%% |
| 世帯類型別 | 世帯主夫婦のみ、世帯主夫婦と子のみ、世帯主夫婦と親のみ、その他・類型不能の4分類%%出典:J-FLEC 統計表の利用上の注意%% |

二人以上世帯全体の1,940万円や720万円と並べる前に、自分の世帯主の年齢と手取り収入に近い区分がないかを探してみてください。持家か非持家かや、子どもの有無に近い世帯類型を選ぶと、並べる相手が自分の生活に近づきます。一人暮らしの人は、単身世帯が別に集計されていて、平均は919万円です%%出典:J-FLEC ポイント%%。

J-FLECの二人以上世帯調査が誰を対象にしているかも、並べる前に確かめておいてください。

| 項目 | J-FLEC 二人以上世帯調査(2025年) |
|---|---|
| 対象 | 全国5,000世帯。世帯主が20歳以上80歳未満で、世帯員が2名以上%%出典:J-FLEC 調査結果ページ%% |
| 方式 | インターネットモニター調査%%出典:J-FLEC 調査結果ページ%% |

世帯主が80歳以上の世帯は、対象に入っていません。80歳以上の世帯主を含む世帯と並べる場面では、この範囲の違いを頭に置いてください。

借入れがある人は、貯蓄の数字だけで見ると位置を取り違えます。家計調査では、貯蓄現在高から負債現在高を引いた純貯蓄額が別に載っていて、世帯主が50歳未満の各年齢階級では、負債現在高が貯蓄現在高を上回っています%%出典:総務省統計局 家計調査 貯蓄・負債編 2025年平均%%。住宅ローンなどの借入れがあるときは、貯蓄の数字と並べて、借入れの残高も書き出しておきましょう。

### 並べる前に、手元で確かめる

チェックがそろわない数字は、自分の貯蓄と並べず、横に置いておいてください。その場合の並べる相手は、前に書き残した自分の金額です。

そろった数字と並べたときも、差の読み方には順番があります。

| 順番 | 確かめること |
|---|---|
| 1 | 自分の金額が、調査と同じ数え方か |
| 2 | 並べた区分が、自分の世帯に近いか |
| 3 | 1と2がそろったうえで、差を見る |

3の差は、中央値より少なくても多くても、目標でも合格ラインでもありません。平均の高さに気持ちが引っ張られたときは、平均を下回る世帯が約3分の2を占める分布だったことを思い出してみてください%%出典:総務省統計局 家計調査 貯蓄・負債編 2025年平均%%。

並べる相手には、前の年の自分もあります。同じ数え方で、同じ時期に書き残した金額なら、増えたか減ったかの差を、ほかの世帯の数字に左右されずに読めます。書き残すときは、合計だけでなく、種類ごとの金額も並べてメモしてください。

| 書き残す項目 | 書く金額 |
|---|---|
| 日常用の預貯金 | 合計には足さず、別に書く |
| 運用や将来に備える預貯金 | 口座ごとの残高 |
| 保険・個人年金保険 | 調査票の数え方での金額 |
| 株・投資信託・債券 | 書き残す日の時価 |
| 借入れ | 同じ日付の残高 |

次の年に増減を見たとき、どの種類が動いたのかまで、自分で確かめられます。

## 次に貯蓄の数字を見かけたとき、先に確かめること

貯蓄の数字は、金額より先に、誰の数字か、平均か中央値か、何年のどの調査の数字かを確かめると、自分と並べていいかが決まります。並べるなら、世帯の形が近い区分の中央値と、同じ数え方にそろえた自分の金額がおすすめです✨

- 平均は、一部の世帯に引き上げられて高く出る数字
- 中央値720万円は、0円の世帯も入れた真ん中で、目標ではない
- 通帳の合計と調査の「金融資産」は、数え方が違う
- 年と調査が違う数字は、大小を比べない
