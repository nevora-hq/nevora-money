高額療養費が8月に見直されたとニュースで見たものの、自分の上限がいくらになったのかは分からないまま、という人もいるかもしれません💦 入院や手術の予定がある人も、毎月の通院が続いている人も、気になるのは、結局自分はいくらまでなのか、というところですよね。

自分の区分の決め方、月の上限の読み方、新しく加わった年間上限の見方を、詳しく説明していきます。

## 高額療養費の8月見直し、自分の上限はいくらになったのか？

ニュースの数字は区分ごとに違うので、自分に当てはまる数字がどれなのか、探しにくいですよね。高額療養費は、ひと月に医療機関の窓口で払った自己負担が上限を超えたとき、超えた分があとから支給される制度です。見直しは、2026年8月に受けた診療分から始まっています%%出典:厚生労働省「高額療養費制度を利用される皆さまへ」%%。

入院や手術の見積りを受け取ったときは、窓口でひと月にいくらまで払えば済むのか、知りたいですよね。毎月の通院治療が続いているなら、1回ごとの窓口払いが小さくても、1年で積み上がる分がどうなるのか、気になるかもしれません。そこへ2026年8月から、年間上限という年単位の上限も加わりました%%出典:全国健康保険協会(協会けんぽ)「高額療養費」%%。

![病院の受付カウンターで、ラックのリーフレットを手に取っている手元](/images/articles/2026-08-31_高額療養費2026年8月見直しと年間上限_body2.webp)

手が止まるのは、自分の区分は年収で決まるのか、見積りのどの金額と上限を見比べればいいのか、年間上限はいつの分から数えるのか、といったところではないでしょうか。見積りの金額が10割の総額なのか、窓口で払う3割の額なのかでも、見比べる相手が変わってきます。窓口の払いも毎月の領収書も、この3つが決まらないと、上限と見比べられません。

## 自分の区分と月の上限は、どの書類のどの数字で決まるのか

見積りを手にしたとき、まず決めたいのは、自分がどの区分なのかです。区分が決まれば、次の一覧表で、月の上限の行が1つに決まります。会社員か国民健康保険かで、見る書類が分かれます。

### 上限の一覧表で、自分の行はどれか

区分を決めるのは、年収そのものではなく、加入先ごとの書類です。会社の健康保険に入っている人は標準報酬月額、国民健康保険の人は所得、住民税が非課税の人は非課税の区分で探します%%出典:厚生労働省「高額療養費制度の見直しについて」(令和8年8月診療分からの資料)%%。

協会けんぽの区分では、住民税が非課税でも、標準報酬月額が53万円以上の2つの区分に当たる人は、非課税の区分に入りません%%出典:全国健康保険協会(協会けんぽ)「高額療養費」%%。まず標準報酬月額か所得で行を探し、住民税が非課税の人は、非課税の行も見てください。

> ⚠️ 注意
> 表の数字は70歳未満の区分で、2026年11月時点の値です。70歳以上は、別の表になります%%出典:厚生労働省「高額療養費制度の見直しについて」(令和8年8月診療分からの資料)%%。

### 書類が見つからないとき、年収の目安はどう当てはめるか

標準報酬月額や所得が載った書類がすぐに見つからないときは、源泉徴収票の支払金額、なければ確定申告書の控えの収入の欄を、一覧表の年収の目安に当てはめて、当たりをつけます。^^境目に近くて迷うときは、2つの行の両方に印を付けてください^^。

あとで加入先の書類で区分が決まったら、印の1つを消せば済みます。区分は加入先が決めるので、年収の目安は、見積りと見比べる前の下準備にとどめてください。

### 定額の区分と、1%を足す区分は何が違うか

年収の目安が約370万円以下の区分と、住民税非課税の区分は、一覧表の金額がそのままひと月の上限になる定額の区分です%%出典:厚生労働省「高額療養費制度の見直しについて」(令和8年8月診療分からの資料)%%。約370万円を超える区分は、定額に1%を足す区分で、読み方が少し違います。

| 区分の種類 | 一覧表で見る欄 | 見比べる金額 |
|---|---|---|
| 約370万円以下と住民税非課税 | 月の上限の金額 | その月に窓口で払った自己負担の合計 |
| 約370万円を超える区分 | 月の上限の式 | 見積りにある10割の総額 |

足すのは、保険が使える診療の総額、つまり窓口で払う3割ではなく10割の額のうち、一覧表の基準額を超えた分の1%です%%出典:全国健康保険協会(協会けんぽ)「高額療養費」%%。見積りを見るときは、==窓口払いの額ではなく10割の総額==を探してみてください。

厚生労働省の例では、70歳未満で年収約370万〜約510万円の人が医療費100万円の治療を受けると、自己負担は約9.3万円までです%%出典:厚生労働省「高額療養費制度を利用される皆さまへ」%%。1%を足す区分では、総医療費が基準額を超えて増えたとき、上限は超えた分の1%ずつ増えていく読み方です。

### 月をまたぐ入院は、見積りをどう見ればよいか

月末に入院して翌月に退院するときは、見積りが1つの総額で出ていても、上限は月ごとに分けて見比べます。自己負担限度額は、同じ月の中で数えるからです%%出典:全国健康保険協会(協会けんぽ)「高額療養費」%%。

| 入院から退院まで | 上限と見比べる単位 |
|---|---|
| 同じ月の中で退院 | その月の1回分 |
| 月をまたいで退院 | 診療を受けた月ごとに分けた2回分 |

入院日と退院日の月が違うときは、見積りに日付ごとの内訳があれば、月ごとに分けてみてください。内訳が無いときは、診療を受けた月ごとの窓口払いの額で、月の上限と見比べることになります。

### 月の上限は、見直しで何から何に変わったのか

自分の上限が何から何に変わったのかは、一覧表の見直し前と見直し後の列を並べると分かります。たとえば約370万〜770万円の区分は、定額の部分が80,100円から85,800円に、1%がかかり始める基準額が267,000円から286,000円に変わりました%%出典:全国健康保険協会(協会けんぽ)「高額療養費」%%。約370万円以下の区分は57,600円から61,500円に、住民税非課税の区分は35,400円から36,900円に変わりました%%出典:全国健康保険協会(協会けんぽ)「高額療養費」%%。

変わったのは月の上限で、多数回該当の金額は据え置かれています%%出典:厚生労働省「高額療養費制度を利用される皆さまへ」%%。

> ⚠️ 注意
> 2027年8月には、所得区分を細かく分ける予定です。細分化は、現在の限度額から著しく増加することがないよう配慮しながら行う予定です%%出典:厚生労働省「高額療養費制度を利用される皆さまへ」%%。細分化後の区分と金額は、公表されたあとに加入先の案内で確かめてください。

### 入院中の食事代は、月の上限に入るのか

入院の費用には、月の上限の外に置かれるものがあるのです。入院時の食事代、入院時生活療養費の自己負担額、保険診療と保険外の診療を併用したときの保険外の差額分は、月の上限の対象になりません%%出典:全国健康保険協会(協会けんぽ)「高額療養費」%%。

月の合計を書き出すときは、これらを別に分けて書いてください。これらを月の合計に入れると、上限に届いていないのに届いたように見えてしまうからです。

### 窓口の払いを、月の上限までにとどめるには

窓口で払う額を月の上限までにとどめたいときは、マイナ保険証を使うか、事前に限度額適用認定証を入手して窓口で提示します%%出典:厚生労働省「高額療養費制度を利用される皆さまへ」%%。認定証は、入院だけでなく外来でも使えます%%出典:厚生労働省「高額療養費制度を利用される皆さまへ」%%。

提示しないと、月ごとの上限を超える分も窓口で支払うことになり、その超えた額が、あとから高額療養費として支給されます%%出典:厚生労働省「高額療養費制度を利用される皆さまへ」%%。認定証の交付の手続きは、加入している健康保険組合・協会けんぽ・市町村などの窓口に問い合わせます%%出典:厚生労働省「高額療養費制度を利用される皆さまへ」%%。入院の日が決まったら、窓口で提示できるよう、この手続きを先に済ませてください。

> ⚠️ 注意
> 認定証の交付の手続きの中身は、加入先ごとに違います。必要な書類や申請の方法は、加入先の案内で確かめてください。

## 毎月の通院が続くとき、年間上限と月の上限の下がり方は、どの月から効くのか？

毎月の通院が続くと、1回の窓口払いが小さくても、1年では積み上がっていきますよね。ここで効いてくるのが、新しく入った年間上限と、以前からある月の上限が下がる仕組みです。年間上限の最初の12か月は、2026年8月から2027年7月です%%出典:全国健康保険協会(協会けんぽ)「高額療養費」%%。

月の上限と年間上限は、数える期間と見比べる金額が違います。

| | 月の上限 | 年間上限 |
|---|---|---|
| 数える期間 | 同じ月の中 | 8月から翌年7月までの12か月 |
| 見比べる金額 | その月の自己負担分の合計 | 月ごとの自己負担額が積み上がった合計 |

### 1年の上限は、いつの分を数えるのか

年間上限は、長期の治療に向けた年単位の上限で、毎年8月から翌年7月までの12か月で数えます%%出典:厚生労働省「高額療養費制度を利用される皆さまへ」%%。月ごとの自己負担額が積み上がっても、年間の上限額に達したあとは、それ以上の自己負担は保険者から払い戻されます%%出典:厚生労働省「高額療養費制度を利用される皆さまへ」%%。

一覧表の年間上限の列で、自分の区分の金額を見てみてください。年間上限に達したかどうかを何の合計で数えるかは、加入先の案内で確かめてください。月の上限と年間上限は別のものなので、月ごとの上限に毎月届かなくても、1年の合計が年間上限に近づくかどうかは、領収書で確かめることになります。合計が年間上限に近づいてきたら、その月以降の領収書を取っておき、年間上限に達したかどうかを8月から数え直して見比べてください。

> ⚠️ 注意
> 年間上限を超えた分の払い戻しは、2027年8月以降です。協会けんぽでは、年間上限額の高額療養費の申請が2027年8月から始まります%%出典:全国健康保険協会(協会けんぽ)「高額療養費」%%。ほかの加入先は、案内で確かめてください。

### 月の上限が下がる月は、どの月を数えるのか

多数回該当は、高額療養費の払い戻しを受けた月が重なったときの仕組みです。直近12か月に払い戻しを受けた月が3か月以上あると、4か月目から月の上限が下がります%%出典:全国健康保険協会(協会けんぽ)「高額療養費」%%。今回の見直しでは、長期の治療で負担が増えないように、この金額は据え置かれています%%出典:厚生労働省「高額療養費制度を利用される皆さまへ」%%。

窓口で限度額適用認定証を使って自己負担限度額を払った月も、払い戻しを受けた月と同じように数えます%%出典:全国健康保険協会(協会けんぽ)「高額療養費」%%。認定証を使って窓口の払いが上限までで済んでいた月も、数え忘れないでください。

> ⚠️ 注意
> 多数回該当は同じ保険者での療養に適用されるため、国民健康保険や健康保険組合から協会けんぽに加入するなど保険者が変わると、それまでの月数は通算されません%%出典:全国健康保険協会(協会けんぽ)「高額療養費」%%。被保険者から被扶養者に変わった場合も通算されません%%出典:全国健康保険協会(協会けんぽ)「高額療養費」%%。

### 領収書を月ごとに並べるとき、何を書き出すか

月ごとに並べると、払い戻しを受けた月が何回あるか、つまり多数回該当と、1年の合計、つまり年間上限の両方が見えてきます。そこで、直近1年の領収書を、==月ごとに並べて==みてください✨ 手元に無いときは、次に受け取る分から、月ごとに取っておくといいでしょう。

並べるときは、医療機関ごと、入院と外来ごとに分けて、月の窓口払いを書き出します。年間上限は8月から翌年7月までなので、並べる順は、1月からではなく8月からにしてください。次のような表を紙やメモに作ると、月の合計も年間の合計も出せます。

|---|---|---|---|---|
| 8月 | | | | |
| 9月 | | | | |

協会けんぽの場合、払い戻しは、高額療養費支給申請書を加入している支部に提出して受けます%%出典:全国健康保険協会(協会けんぽ)「高額療養費」%%。処方せんで調剤薬局を使ったときの自己負担額は、処方せんを出した医療機関の自己負担額に合算して計算します%%出典:全国健康保険協会(協会けんぽ)「高額療養費」%%。世帯での合算は、同じ協会けんぽの被保険者とその被扶養者が、同じ月に複数の受診をしたときに使えます%%出典:全国健康保険協会(協会けんぽ)「高額療養費」%%。70歳未満は、1つの医療機関の入院や外来ごとの自己負担が21,000円以上のものだけが合算の対象になるので、月の合計は目安です%%出典:全国健康保険協会(協会けんぽ)「高額療養費」%%。

> ⚠️ 注意
> 領収書には、払い戻しを受けたかどうかは載っていません。払い戻しを受けた月と、認定証を使って窓口払いが上限までで済んだ月は、どちらも多数回該当の月数に数えるので、表に印を付けてください。

### 払い戻しまでの立て替えが重いとき、頼れる制度はあるか

払い戻しを待つあいだの立て替えが重いと感じるときは、協会けんぽの高額医療費貸付制度があります。高額療養費の支給見込額の8割相当額を、無利子で貸し付ける仕組みです%%出典:全国健康保険協会(協会けんぽ)「高額療養費」%%。

申請には、保険点数が分かる医療機関発行の医療費請求書、高額医療費貸付金借用書、高額療養費支給申請書を、加入している協会けんぽの支部に提出します%%出典:全国健康保険協会(協会けんぽ)「高額療養費」%%。貸付金の返済には、支給申請した高額療養費の給付金が充てられます。医療費の減額や不支給などで貸付金が返済されなかったとき、または不足したときは、返納通知書が届くので、期日までに返納します%%出典:全国健康保険協会(協会けんぽ)「高額療養費」%%。協会けんぽ以外の加入先は、貸付の有無を加入先の案内で確かめてください。

ここまでで確かめたことを、上の5つで、手元の状態に当てはめてみてください。区分と月の上限が決まっているかも、ここで分かります。

## 次の見積りや領収書で、最初に見比べる相手

高額療養費の見直しで見るのは、ニュースの数字ではなく、自分の区分の月の上限です。区分の決め方と読み方が決まれば、見積りや領収書と見比べられます。

- 区分を決める、加入先ごとの書類
- 定額だけの区分と、定額に1%を足す区分で違う、月の上限の読み方
- 通院が続くときの、8月からの領収書の並べ方と、月の上限・年間上限との見比べ

> 💡 NEVORAポイント
> 次に入院や手術の見積り、または毎月の領収書を受け取ったときは、==自分の区分の月の上限==と見比べてください。上限に届いた月は、印を付けておいてください。
