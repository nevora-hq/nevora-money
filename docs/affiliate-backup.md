# アフィリエイトリンク削除台帳

お金サイトで使う ASP は【未確定: お金サイトのASP】。

## 背景・方針

AdSense審査を最優先するため、審査リスクとして残す意味のない既存アフィリエイトリンクを削除する場合は、次の方針で行い、ここに台帳として記録する(詳細方針はユーザー指示を参照)。

- 削除対象は `サイト運営\記事データ\公開済み` / `公開済み` 側の記事frontmatter(`affiliateLinks:`)および、本文Markdown中で当該URLに直接張られていたリンク(`[label](URL)`、多くは末尾に `(PR)` 表記付き)。
- 表示機構(`lib/posts.js` の `embedAffiliateBanners`/`renderAffiliateBannerHtml`、`components/AffiliateBanner.js`、`pages/posts/[slug].js` の `post.affiliateLinks?.length > 0` 条件付き注意書き)は**削除していない**。frontmatterの `affiliateLinks` が空/未指定なら何も表示されない設計のため、本ページの情報を**同じキー・URL・画像URLでfrontmatterに復元するだけ**で再掲載できる。
- 各記事本文中の「※本記事にはアフィリエイト広告(PR)を含みます。当サイトを経由して...」という手書きの注意書き段落も、実態(PRリンクなし)に合わせて削除する。貼り直し時はこの一文も復元すること。
- `pages/compare.js` は `items`(=全記事の `affiliateLinks` を集約したもの)が0件のとき、ページ上部の固定注意書きを `items.length > 0` の条件付きで表示する。リンクを復元すれば自動的に再表示される。

## 追加削除

一括削除の対象範囲(`公開済み`)に含まれていなかった`下書き`フォルダ内の、同名記事の**別ファイル(重複下書き)**やリライト版にだけ元のアフィリエイトリンクが残ることがある。**教訓**: 同一記事が複数フォルダ(下書き/公開済み)に重複して存在するケースでは、一括処理の対象範囲を「フォルダ」ではなく「記事(ファイル名)」単位で洗い出すこと(フォルダ単位のスコープだと重複ファイルを見落とす)。

| 記事 | 商品名 | 元URL | 画像URL | ASP |
|---|---|---|---|---|

削除内容: frontmatter `affiliateLinks`、本文中の該当商品への直リンク・比較表内の該当行、末尾の「※本記事にはアフィリエイト広告を含みます。」の注意書き。

上記の教訓を踏まえ、`公開済み`/`下書き`全フォルダを対象にアフィリエイトリンクパターン(`a8.net`等のASPドメイン、`affiliateLinks:`、PR表記文言)を再検索し、追加の残存がないことを確認する。実在ASPリンクではない`example.com`のプレースホルダーURLや、アフィリエイトリンク挿入用のHTMLコメント・PR表記も、全カット方針(実在有無を問わず記事にアフィリエイト言及自体を残さない)に従い削除する。

## 貼り直し時の手順

1. 上表のURL・画像URLは提携解消の可能性があるため、貼り直し前にASP(お金サイトのASPは【未確定: お金サイトのASP】)の管理画面でリンクの有効性を再確認すること(URLをそのまま使い回さない)。
2. 該当記事のfrontmatterに `affiliateLinks:` を復元する(`docs/citation-format.md`と同様、`lib/posts.js`の`normalizeAffiliateLinks`が`label`/`url`/`image`キーを受け付ける)。
3. 本文中の該当箇所に `[商品名](URL)` の形でリンクを再設置する(`embedAffiliateBanners`は本文中の`href`一致でバナーを自動挿入するため、frontmatterと本文の両方にURLが必要)。
4. 「※本記事にはアフィリエイト広告(PR)を含みます。」等の注意書きは、`pages/posts/[slug].js`側で`post.affiliateLinks?.length > 0`のとき自動表示されるため、本文に手書きで再度追加する必要は**ない**(手書きの重複表示を避けるため)。
5. `pages/compare.js`は全記事の`affiliateLinks`を自動集約するため、追加の手作業は不要(`items.length > 0`の条件付き表示)。
6. お金の記事に貼り直すときは、手順4の自動表示に加えて、広告を含むことを読者が気づける大きさ・位置で常に明示する(提携の有無や順位への影響にかかわらない。不当景品類及び不当表示防止法〔景表法〕5条3号の告示〔ステマ規制〕のねらい)。それとは別に、比較・ランキングで提携の有無が順位・掲載に影響する場合はその旨と、順位の根拠(評価基準・時点)を冒頭付近に置く。手数料・金利・還元率・キャンペーンの条件(対象・期間・上限・エントリー要否)を小さく・離して書かない。貼り直した記事は法務チェックを通してから公開する。
