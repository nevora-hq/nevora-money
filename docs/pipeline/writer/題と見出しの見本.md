# 題と見出しの見本(規則30・31の見本。規則ではない)

規則の本体は `.claude/agents/writer.md` の規則30(題名)・規則31(見出し)・規則32(本文と部品)である。このファイルは、その見本を金融の題材で示すだけで、規則を足さない(規則の本文はここに置かない。2026-11-19に別サイトの見本を読み替えて新設し、2026-11-20 に、依頼者の決定で、元資料の規則30・31と見本〔題と見出しの見本。2026-09-26〕を正として見直した。見本は、設計役の暫定・参考で、合否に使わない)。

使い方の注意:
- 下の例は**案**である。制度・数値・手数料の事実は、本文と一次情報で確かめてから使う(確かめていない例を、そのまま題名・見出しに使わない)。
- 題名に入れる数字は、数のフック(本文の項目数と必ず合わせる)だけで、答えにあたる数字は入れない(規則30(f))。字数は40字までを目安(28〜32字が目安。参考で合否に使わない。規則30(d))。
- **題名・見出しに絵文字を付けない**(依頼者の決定 2026-11-20。規則30(e)・31(j))。サイトのコードが目次に自動で付ける絵文字は、書き手の対象外。下の例にも絵文字は無い。
- 「必ず」「確実」「絶対」「儲かる」「損しない」「〇万円得する」「〜すれば大丈夫」は、題名にも見出しにも本文にも書かない(規則30(g)・CLAUDE.md の金融YMYLの節)。下の表の「悪い例」は、直す前の形を示すためだけに載せている。

## 1. 題の型(規則30(b))の例

| 型 | 例 | 注 |
|---|---|---|
| A 問い(Know・一問一答) | 新NISAのつみたて投資枠と成長投資枠は何が違う？ | 答えは本文。疑問のあとに答えの方向・数を置かない |
| A 問い(Compare。決め手は題名に置かない) | iDeCoと新NISA、先に始めるのはどっち？ | 候補を並べる形はよい。「〜が決め手」は置かない |
| A 問い(Judge。検索意図の(e)が高い場合は規則30(c)で判断の枠) | ふるさと納税をしたら確定申告は要る？｜要るかどうかの境目 | 境目の中身は本文。個別の税額・税務判断は書かない |
| B 状況描写＋約束(Do・一問一答) | 月末になると口座の残高が足りない｜引き落とし日と固定費の見直し方 | 前半に読者の場面、後半に主キーワードと約束 |
| C キーワード＋副題(Buy・網羅) | クレジットカードの選び方｜年会費・ポイントの付き方・使える場所で比べる | 副題に比較の軸を入れる |
| D 逆説(本文に「思い込み ≠ 実際」があり、一次情報で裏付く記事だけ) | リボ払いの「月々の負担が軽い」は本当か｜手数料のかかり方 | 読者が実際に持つ思い込みのときだけ(規則21(a))。根拠は約款・金融庁・消費者庁の資料で確かめてから使う |
| E 原因の問いかけ(Why・深掘り) | リボ払いの残高はなぜ減りにくいのか｜毎月の支払額と手数料の関係 | 同上 |

**副題で足してよいもの(元資料の見本のA型「疑問＋続きを読む理由」)**: 答えではなく、**何を見るか(比較の軸・分類の軸)と、根拠の出どころ**。例: 「ポイントを使うと家計簿は合わなくなる？ポイントと現金の2つの入り口」(2つの入り口という見る軸が副題)、「年末調整で足りるか、確定申告が要るか｜収入の入り方で分かれる条件」(分かれる軸)。答えの方向・条件・例外・目安・数を、疑問のあとに置かない。

採用しない形: 疑問のあとに答え・決め手・目安を置く形(「〜は〜？→結論」「〜が決め手」「〜の目安は〇%」。規則30(b)(f))。元資料の旧見本のA型「問い＋答え型」(疑問→結論または結論の枠。「〜は〜？→〜」「〜が決め手」「〜の目安と〜」)は、元資料自身の規則30(b)(2026-10-20 の決定)が「答えは題名に置かず、本文に書く。単一の答えを題名に置く形は禁止」と改めたので、見本として載せない(元資料の見本でも、続きを読む理由は「条件・例外・目安」ではなく、副題の見る軸・根拠の出どころで作る)。

## 3. 見出しの表側(規則31(d))の例

- 場面: 積立の設定画面を開いたまま、手が止まる
- 疑問: 毎月同じ額を入れているのに、なぜ残高が思ったほど増えないのか
- 反転(根拠が強の節だけ。問いの形): 手数料は、毎月の額ではなく残高にかかるのか
- 判断(個別の投資判断・個別の税務判断は除く): 一括で払うか、分割で払うかの境目
- 行動(締め。方向だけ): リボ払いの残高を確かめたあとの次の一歩
- 文末の温度(参考。本数では決めない。規則31(g)(h)): 疑問止めは中〜高、体言止めは低〜中(判断・締め向き)、途中で切る形・呼びかけは高(乱用しない)、手順の終止形は低(見出しに手順を書かないので使わない)。元資料の見本にあった本数の制限(疑問止めはH2で2本まで・途中で切る形は1記事1本まで・呼びかけは最初の1本まで)は、元資料自身が2026-11-02 の決定(規則31(g)(h))で外したので、載せない。上から読んで文末が単調にならないかで判断する
- 見出しのリズムの例(例であって型ではない。規則31(h)): 疑問で入る(毎月確認しているのに、なぜ月末に足りなくなるのか) → 場面で受ける(引き落としの前日に、残高を見て手が止まる) → 体言止めで判断の枠を示す(削るか、待つかの境目) → 行動の方向で締める(次に引き落としの通知が来たあとの一歩)。答えは各節の本文で渡す

採用しない形: 反転を言い切る見出し(「〜は〜で決まる」。元資料の見本の「電気代は使う時間より待機の数で決まる」の形)、行動を手順で書く見出し(「先に〇〇を入れる」。元資料の見本の「次に更新通知が来たら、先に解約日を入れる」の形)、見出しの絵文字。見出しに答え・手順を書かない(規則31(d))。元資料の規則31(d)も、反転は問いの形、行動は方向だけとしている。

## 4. 対応表の例(規則31(a)・規則12。リボ払いの記事)

「出典の有無」「問題点」の欄は、既存記事の見出しを直すときだけ足す(規則31(l))。

| 現在のH2(表側) | 裏側(本文の主張) | 根拠 | 判定と案 |
|---|---|---|---|
| 毎月の支払いが同じなのに、残高が減らない | 支払額が一定でも、残高に手数料がかかり続ける(約款・金融庁の資料) | 強 | 維持。場面型＋疑問止め |
| 手数料は、残高にかかるのか | 手数料は元金の残高に年率がかかる(約款) | 強 | 維持(反転型を問いの形で) |
| 手数料を抑えるには、増額返済を使う | 増額返済で残高が減れば手数料も減る(約款。条件は会社ごと) | 中 | 「決まる」「必ず減る」と書かない。「増額返済で変わること」(体言止め) |
| 返済が長引くとき、疑う順番 | 残高・年率・追加の利用を順に確かめる | 弱〜中 | 弱める案: 「残高が減らないとき、確かめる順番」。根拠を足す案: 約款・公式の試算の資料を足して維持 |

(表の事実は例。使うときは一次情報で確かめる。リボ払いは手数料が増えて総支払額が増える商品であり、記事では手数料・総支払額が増えることを併記する。)

### 文末がそろっているときの直し方の例(元資料の見本の例2を、家計の題材で。規則31(h))

内容(裏側)は変えず、表側の文末だけを変えて緩急を作る。

| 現在のH2の文末 | 直し方 |
|---|---|
| 全部が手順の終止形(〜を見る／〜をやめる／〜を確かめ直す)で、目次が作業の指示のように並ぶ | 2本目は場面型＋途中で切る形、3本目は問いの形、4本目は判断の枠(体言止め)、5本目は行動の方向に変える。手順は本文に書き、見出しには書かない |

## 5. 載せない例(今の規則と反対のもの)

- 主張の無いつなぎの見出し(規則12)
- 専門家に相談する目安の見出し(「FPに相談するか、様子見か」。規則24。窓口を答えにしてよいのは、犯罪に関わる被害がいま起きていて個人では対処できない場面だけ)
- 「今夜は〜を確かめる」のような時間の決めつけ(規則11(2)・14)
- 体験談の題・見出し(「証券口座を開くか30分迷った話」。B5)
- 「これって普通？」のような、検索語が無い見出し・代名詞で始まる見出し(規則31(j))
- H2の1本目に主キーワードが無い案(規則31(j))
