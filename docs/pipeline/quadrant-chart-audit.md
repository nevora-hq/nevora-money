# quadrantチャート誤読リスク監査

対象: `type: "quadrant"`チャートを持つ全記事(確定稿・公開済み)。

背景: 費用感などY軸の値が高いほど高額=悪い軸で、高い方に◎がつくと「サービスを利用する方法は費用面で優れている」と誤読されるリスクがある。そのため`lib/posts.js`の`renderQuadrantChartHtml`は、◎○△の評価記号を廃止して中立的な高低表現(「高い/中程度/低い」)をデフォルトにしている(CONTRIBUTING.md §20参照)。この変更により記号由来の誤読リスクはコード側で解消される。

以下は、軸の意味が「高い=悪い(費用・価格など)」であるためレンダラー修正後も文言(「高い/中程度/低い」)だけでは実感に合わない可能性がある記事の一覧。**修正はユーザーの確認後に行う(本監査は報告のみ)。**

## 誤読リスクあり(費用・価格軸で「高い=悪い」の意味を持つ)→ 再点検の結果

| 記事 | 軸 | 再点検結果 |
|---|---|---|

判定のしかた:

- `note`フィールドを持つチャートは、レンダラーの中立化(◎○△→「高い/中程度/低い」)が適用され、評価含意を持つ記号は残らない。個別の`xNote`/`yNote`(例:「約44,000円/年」)を追加すればより親切だが、誤読リスクという観点では既に解消しているため必須ではない。
- `note`ではなく`source`のみを持つチャートは、レンダラーの分岐条件(`note`の有無)により、フォールバック表は記号・磁気語のいずれでもなく**座標の生数値がそのまま表示される**。◎○△由来の誤読は発生しないが、「座標値をそのまま数値で見せると測定値であるかのような誤解を招く」というquadrant設計時の懸念には抵触したままであり、別種の課題として残る(優先度: 低、対応は`note`追加の要否も含めユーザー判断待ち)。

## 誤読リスク低(軸の値が高い=良い、またはニュートラルな属性)

両軸とも「値が高い=一般に好ましい、または単なる特性の強弱(良し悪しの評価を伴わない)」である記事は、記号除去・中立表現化により誤読リスクは実質的に解消しており、追加対応は不要と判断する。

## まとめ

- 記号(◎○△)由来の誤読リスクは`lib/posts.js`の修正により解消済み(コード修正のみで対応、記事側の追加修正は不要)。
- 費用・価格軸を持つ記事は、`xNote`/`yNote`で具体的な文言を追加すると更に親切だが、軸ラベル自体に方向性の説明がある記事は優先度低。
- お金の記事の quadrant では、信託報酬(年率)・年会費・保険料・手数料などの費用軸は「高い=悪い」側になる。軸ラベルに方向の注記(低い←→高い)を付け、`xNote`/`yNote` で具体的な文言(例: 「年率0.1%台」「年会費無料」)を足す。座標は公式の実データで決め、主観の軸(おすすめ度・安心感)は使わない。
