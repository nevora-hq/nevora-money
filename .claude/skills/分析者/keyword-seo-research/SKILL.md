# SEOキーワード・トレンド調査スキル(分析者)

## 手順
1. WebSearchで以下の軸を必ず調べる
   - 「(テーマ) おすすめ 比較 ランキング」— 購入直前の検索意図・競合アフィリエイト記事
   - 「(テーマ) 悩み 原因 対策」— 情報収集段階の検索意図
   - 「(テーマ) トレンド 話題 年月」— 業界レポート・調査データ・SNSの話題
2. 検索意図(情報収集/比較検討/購入直前)ごとにキーワードを分類する。購入直前の意図はアフィリエイト収益に直結するため優先的に拾う
3. 検索上位の競合記事を数件確認し、構成・見出し・アフィリエイト案件の入れ方を分析する
4. **競合記事に共通して「書かれていないこと・弱いこと」(情報の古さ、具体性の欠如、独自データの不在など)を最低1つ特定する。** ここが自社記事の差別化ポイントになる。単なる競合構成のコピーで終わらせない
5. 出典URL・数値データを必ず控える(裏取り不可な情報は「未確認」と明記)
6. 調査結果は `テーマ_キーワード調査.md` 形式でファイル保存し、writerが直接使える形(概要・キーワード一覧・競合分析・出典一覧)にまとめる

## チェックリスト
- [ ] 出典URLは最低2件以上
- [ ] メイン/関連/ロングテールキーワードに分類したか
- [ ] 検索意図(情報収集/比較検討/購入直前)を明記したか
- [ ] 競合記事に対する差別化ポイント(競合の弱点・不足点)を具体的に言語化したか
- [ ] 数値データ(%、件数など)は出典元の文言のまま引用しているか
- [ ] 推測と事実が明確に分かれているか
