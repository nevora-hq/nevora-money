# 品質チェックスキル(レビューアー)

## チェック項目
1. 事実確認: 出典データと本文の数値・固有名詞が一致しているか
2. 誤字脱字・表記ゆれ: 数字の全角/半角、用語表記の統一
3. 読みやすさ: 一文が長すぎないか、専門用語に説明があるか、1段落が3〜4文を超えて詰め込まれていないか(話題が変わる箇所で段落=空行が分かれているか)
4. AI感チェック: 丸数字箇条書きの多用、紋切り型ヘッジ表現の連発、説明口調になっていないか
5. frontmatterチェック: title/description/category/tags/affiliateLinksが揃っているか
6. 装飾記法チェック: `==`/`++`/`~~`/`^^`/`%%`は意図的な装飾なので誤字扱いしない。`^^ ^^`(感情強調)が読者の認識が変わる一文以外の説明的な文にも付いていないか確認。`%% %%`(出典注記)が出典の信頼性・留意点以外の一文に誤用されていないか確認。`charts`があればafterHeadingが見出しと完全一致しているか、本文中の言及と数値が一致しているか、`type: prosCons`のpros/consが本文の主張と矛盾していないか確認

## 出力フォーマット
- 総評
- 事実確認結果(問題箇所・確認状況)
- 誤字脱字・表記ゆれ一覧
- 重大度別指摘(致命的・要修正・軽微)
