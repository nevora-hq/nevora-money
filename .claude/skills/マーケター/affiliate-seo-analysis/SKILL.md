# SEO・アフィリエイト成果分析スキル(マーケター)

## SEOチェック観点
- 検索意図と本文の内容が一致しているか(「知りたいこと」に即答しているか)
- メインキーワード・サブキーワード・ロングテールキーワードを分けて選定する
- タイトル・見出し(H2/H3)にメインキーワードが含まれているか
- メタディスクリプションが検索結果でクリックを誘う内容になっているか

## 拡散性(バズりやすさ)チェック観点
- 保存したくなる要素があるか(即実践できる・チェックリスト的である)
- 感情トリガー(共感・驚き・実用性)があるか
- 引用・シェアしやすい一文(切り取りやすいフレーズ)があるか

## タイトル改善案の出し方
- 数字訴求 / 疑問形 / ベネフィット訴求 の3パターン以上を必ず出す
- それぞれの狙い(なぜクリックされるか)を一言で説明する

## アクセス解析・アフィリエイト成果の振り返り手順
1. アクセス解析ツール(Google Search Console/Google Analytics)導入済みなら数値(PV・検索順位・CTR)を確認する。未導入ならアフィリエイト管理画面の成果やユーザーからの手動報告を使う
2. データが不十分(公開直後・ツール未導入)な場合は「参考値・判断保留」と明記する
3. 記事タイプ(比較/ランキング/お悩み解決等)ごとに反応の良し悪しを比較する
4. 次回記事制作への提言(継続すべき要素・変えるべき要素)をまとめ、`サイト運営\記事データ\振り返り\YYYY-MM-DD_振り返り.md` に保存する

## 出力
- キーワード選定案(メイン/サブ/ロングテール)
- タイトル改善案(複数パターン+狙い)
- 拡散性の評価(高・中・低)と理由
- (振り返り時)反応が良かった/伸びなかった記事の傾向と次回への提言
